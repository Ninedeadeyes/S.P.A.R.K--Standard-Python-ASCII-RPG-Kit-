Project Overview

SPARK is a light weight 2d Retro Ascii RPG Game Engine. It is build on the standard library hence no PIP install is required. 

The purpose of the engine is educational. I consider it an extension of my 15 mini python games tutorial series, it acts like a playground 
where you can apply what you have learnt into your own mini adventures 

I have hard coded a simple fetch quest 'Spoon Quest' into the engine as an example.  When you create your own 
games you should remove all elements of the example before you start.
